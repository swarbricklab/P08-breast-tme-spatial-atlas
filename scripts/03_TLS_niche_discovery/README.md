# 03_TLS_niche_discovery

Find tertiary lymphoid structures (TLS) in the Visium cohort, resolve their internal niches (T cell zone, B cell zone, germinal center (GC), HEV) and derive a gene signature for each niche. All scripts use the `spatial-pilot` environment and run in the order listed.

- **01_identify_TLS/** — TLS scoring and grouping.
  - `01_run_TLS_model.py`: score each spot with the TLS model of [Andersson et al. (2021)](https://doi.org/10.1038/s41467-021-26271-2).
  - `02_group_TLS_high.py`: group spatially contiguous TLS-high spots.
  - `03_TLS_spatial_organization/`: number, size, spatial clustering and tumour topology of discrete TLS across the cohort (Extended Data Fig. 3b); see its [README](01_identify_TLS/03_TLS_spatial_organization/README.md).
- **02_identify_TLS_niches/**
  - `01_cluster_TLS_high.py`: integrate and cluster TLS-high spots across samples to identify the niches (Supplementary Table 4).
- **03_extract_niche_signatures/** — niche signatures (Supplementary Table 5).
  - `01_extract_niche_signatures.py`: marker genes per niche cluster.
  - `02_filter_GC_signature.py`: remove GC signature genes that are also expressed in epithelial spots (e.g. proliferation genes).
  - `03a_identify_endothelial_high.py`, `03b_create_endothelial_object.py`: collect endothelial-high spots across samples as a background for the HEV signature.
  - `03c_filter_HEV_signature.py`: remove HEV signature genes that are expressed in endothelium generally.
  - `04_organize_signature_files.py`: collect the filtered signatures (top 300 genes each) in one folder.
- **04_map_niche_signatures/**
  - `01_score_signatures.py`: score all spots for the niche signatures.
  - `02_group_high_score_areas.py`: group contiguous high-scoring spots, e.g. to count GCs per section.

`04_map_niche_signatures/01_score_signatures.py` (and `04_vascular_microenvironment/01_identify_HEV_niches/01_score_signature.py`) score the signatures published with the manuscript, [resources/gene_lists/TLS_niche_signatures/niche_signatures.csv](../../resources/gene_lists/TLS_niche_signatures/niche_signatures.csv). To score the signatures regenerated by step 03 instead, set `use_resource_signatures = False` in the script.
