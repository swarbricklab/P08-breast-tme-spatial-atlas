Layout of the inputs after `dvc pull` (see data/README.md). {section_id} is a sample sheet
section ID (e.g. P01_Vis, P26_HD, P17_Xe5k), {level} a cell type annotation level
(major, minor, subset); "..." stands for one file per section.
