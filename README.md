# P08-Spatial-Benchmarking-Analysis-for-publication

Analysis repository for spatial transcriptomics profiling of tertiary lymphoid structures (TLS) and high endothelial venules (HEV) in breast cancer using Visium, Visium HD, and Xenium platforms.

Link to Project description shared doc: [https://docs.google.com/document/d/1iX6YIyb9QG2PgjWokKXowN9cFGbwofTZ/edit?usp=sharing&ouid=108068971437548737290&rtpof=true&sd=true](https://docs.google.com/document/d/1iX6YIyb9QG2PgjWokKXowN9cFGbwofTZ/edit?usp=sharing&ouid=108068971437548737290&rtpof=true&sd=true)

## Repository Structure

### [scripts/](scripts/)
All analysis scripts organized into sequential workflows (preprocessing, cell type mapping, TLS niche discovery, vascular microenvironment analysis, xenium mechanisms) and figure generation scripts. Includes bash scripts for HPC job submission. See [scripts/README.md](scripts/README.md) for details.

### [data/](data/)
Input data including AnnData objects, H&E images (OME-TIFF format), and pathology annotations. Files are organized by platform (Visium, Visium HD, Xenium) and tracked with DVC. See [data/README.md](data/README.md) for details and [docs/tree.txt](docs/tree.txt) for a snapshot of the data organization.

### [resources/](resources/)
Reference data including curated gene signatures, cell type hierarchies, standardized color palettes, and tissue metadata. See [resources/README.md](resources/README.md) for details.

### [config/](config/)
Configuration files including sample sheets (organized by platform and tissue type), parameter files (`params.sh`), and donor ID mappings used throughout the analysis workflows.

### [environment/](environment/)
Conda environment YAML files for reproducible software environments. Different environments were used for various analysis steps and platforms.

### [results/](results/)
Analysis outputs generated by scripts including processed data tables, differential expression results, signature scores, and other computational results. Cell type mapping results (deconvolution and label transfer) can be placed here to run downstream analyses without re-running the cell type mapping step. See [docs/tree.txt](docs/tree.txt) for the expected file organization.
