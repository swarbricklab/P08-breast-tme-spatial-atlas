# Data

This directory contains all input data for the spatial transcriptomics analysis, organized by data type and platform.

## Directory Structure

### anndata_objects/

Preprocessed spatial transcriptomics data stored as AnnData objects (`.h5ad` format):

- **sc_ref/** - Single-cell RNA-seq reference atlas for cell type deconvolution and label transfer, constructed from raw data obtained from [GEO: GSE176078](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE176078). Created by [../scripts/02_cell_type_mapping/visium_deconvolution/01_prepare_sc_ref/01_create_GEO_miniatlas_object.py](../scripts/02_cell_type_mapping/visium_deconvolution/01_prepare_sc_ref/01_create_GEO_miniatlas_object.py).
- **visium/** - Visium spatial data (55 µm spot resolution). Generated by [../scripts/01_preprocessing/visium/](../scripts/01_preprocessing/visium/).
- **visium_hd/** - Visium HD spatial data at multiple bin sizes (2 µm, 8 µm, 16 µm, 48 µm square bins). Generated by [../scripts/01_preprocessing/visium_hd/](../scripts/01_preprocessing/visium_hd/).
- **xenium/** - Xenium spatial data (single-cell resolution). Generated by [../scripts/01_preprocessing/xenium/](../scripts/01_preprocessing/xenium/).

These files are generated by preprocessing scripts and contain gene expression matrices, spatial coordinates, and associated metadata.

### images/

Hematoxylin and Eosin (H&E) stained images in OME-TIFF format (`.ome.tif`):

- **visium/** - H&E images for Visium samples
- **visium_hd/** - H&E images for Visium HD samples  
- **xenium/** - H&E images for Xenium samples

Images are aligned to spatial coordinates and used for visualization and pathology annotation. The pyramidal OME-TIFF format can be easily viewed by dragging and dropping files into [QuPath](https://qupath.github.io/).

### pathology_annotations/

Pathologist annotations of tissue compartments and structures at the spot/bin level (CSV format):

- **visium/** - Spot-level annotations for Visium samples. Annotations were performed in multiple layers (epithelial, immune, and stromal features annotated separately), with a final collapsed column (`single_layer`) providing a single annotation label per spot barcode.
- **visium_hd/** - Bin-level annotations for Visium HD samples, performed on 8 µm bins. Each bin received a single annotation label (not done in layers).
- **visium_lymph_nodes/** - Germinal center annotations for lymph node samples (CSV (spot-level) and GeoJSON formats). GeoJSON files can be visualized in [QuPath](https://qupath.github.io/) by first opening the corresponding H&E image, then dragging and dropping the GeoJSON file into QuPath.

Annotations assign spatial locations to tissue compartments such as epithelial (e.g., invasive, in situ, normal), stroma (e.g., fibrous, adipose), immune infiltration, and blood vessels.

### spatialdata_objects/

SpatialData objects for Xenium samples (`.zip` format):

- **xenium/** - Comprehensive spatial data containers including transcripts, cell boundaries, and metadata. Generated by [../scripts/01_preprocessing/xenium/01_make_objects/01b_make_spatialdata_objects.py](../scripts/01_preprocessing/xenium/01_make_objects/01b_make_spatialdata_objects.py).

[SpatialData](https://spatialdata.scverse.org/) is a framework for integrated analysis of transcript-level and cell-level spatial information. **Note:** These `.zip` files need to be unzipped before they can be read. See [../scripts/figures/figure5/5B.py](../scripts/figures/figure5/5B.py) (lines 95-99) for an example of how to unzip and read these objects.

## Data Version Control

Large data files are tracked using DVC (Data Version Control). The `.dvc` files in this directory point to the actual data locations and enable reproducible data management.
