# Data

This directory contains all input data for the spatial transcriptomics analysis, organized by data type and platform. For a visual overview of the complete file structure, see [../docs/tree.txt](../docs/tree.txt).

## Directory Structure

### anndata_objects/

Preprocessed spatial transcriptomics data stored as AnnData objects (`.h5ad` format):

- **sc_ref/** - Single-cell RNA-seq reference atlas for cell type deconvolution and label transfer, constructed from raw data obtained from [GEO: GSE176078](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE176078). See [../resources/README.md](../resources/README.md) for additional details on how to recreate this object.
- **visium/** - Visium spatial data (55 µm spot resolution). Generated by [../scripts/01_preprocessing/visium/](../scripts/01_preprocessing/visium/).
- **visium_hd/** - Visium HD spatial data at multiple bin sizes (2 µm, 8 µm, 16 µm, 48 µm square bins). Generated by [../scripts/01_preprocessing/visium_hd/](../scripts/01_preprocessing/visium_hd/).
- **xenium/** - Xenium spatial data (single-cell resolution). Generated by [../scripts/01_preprocessing/xenium/](../scripts/01_preprocessing/xenium/).

These files are generated by preprocessing scripts and contain gene expression matrices, spatial coordinates, and associated metadata.

### images/

Hematoxylin and Eosin (H&E) stained images organized by image type and platform. The images directory contains several subdirectories that serve different purposes in the spatial transcriptomics analysis workflow:

#### he/aligned_images/

H&E images in OME-TIFF format (`.ome.tif`) that serve as the reference for spatial coordinates recorded in the corresponding AnnData objects. These images can be directly used for plotting spatial data on full-resolution images (e.g., zooming into specific tissue contexts). The pyramidal OME-TIFF format enables efficient visualization at multiple resolutions and can be viewed by dragging and dropping files into [QuPath](https://qupath.github.io/).

- **visium/** - Aligned H&E images for Visium samples.
- **visium_hd/** - Aligned H&E images for Visium HD samples.
- **xenium/** - Aligned H&E images for Xenium samples.

**Example usage:** See [../scripts/figures/figure3/3A.py](../scripts/figures/figure3/3A.py) (lines 140-160) for an example of loading aligned images and using the `crop_coord` parameter in spatial plotting functions to zoom into specific tissue regions.

#### he/alignment_files/

Alignment files that record the spatial registration between H&E images and capture arrays, organized by platform:

- **visium/** - JSON files generated by manual alignment in 10x Genomics Loupe Browser. These files record the alignment between the H&E image (from `aligned_images/`) and the CytAssist image, which defines the physical location of capture spots. These alignment files were provided to Space Ranger during processing. **Note:** Some lymph node samples used automatic alignment and do not have JSON files here.
- **xenium/** - Transformation matrices (`{sample_id}_matrix.csv`) that record the spatial registration between Xenium transcript coordinates and the H&E image (from `aligned_images/xenium/`). These matrices are used by preprocessing scripts to transform Xenium coordinates into image space for visualization. The matrices were originally generated by manual alignment in Xenium Explorer and can be used to view the Xenium data overlaid on the H&E image in Xenium Explorer. See [10x Genomics documentation on image alignment](https://www.10xgenomics.com/support/software/xenium-explorer/latest/analysis/xe-image-alignment) for details on how to use these alignment files.

#### cytassist/

CytAssist images (`.tif` format) that show the capture array and are used to determine spot locations:

- **visium/** - CytAssist images for Visium samples. Space Ranger uses these together with the alignment files to map spots to the H&E image coordinates.
- **visium_hd/** - CytAssist images for Visium HD samples.

### pathology_annotations/

Pathologist annotations of tissue compartments and structures at the spot/bin level (CSV format):

- **visium/** - Spot-level annotations for Visium samples. Annotations were performed in multiple layers (epithelial, immune, and stromal features annotated separately), with a final collapsed column (`single_layer`) providing a single annotation label per spot barcode.
- **visium_hd/** - Bin-level annotations for Visium HD samples, performed on 8 µm bins. Each bin received a single annotation label (not done in layers).
- **visium_lymph_nodes/** - Germinal center annotations for lymph node samples (CSV (spot-level) and GeoJSON formats). GeoJSON files can be visualized in [QuPath](https://qupath.github.io/) by first opening the corresponding H&E image, then dragging and dropping the GeoJSON file into QuPath.

Annotations assign spatial locations to tissue compartments such as epithelial (e.g., invasive, in situ, normal), stroma (e.g., fibrous, adipose), immune infiltration, and blood vessels.

### processed/

Raw outputs from 10x Genomics pipelines, which are used as input to create the preprocessed AnnData objects in `anndata_objects/`. These directories contain the unmodified pipeline outputs before any custom preprocessing or quality control filtering.

#### spaceranger_outs/visium/

Space Ranger outputs for Visium samples (55 µm spots). Each sample directory contains standard Space Ranger outputs including:
- Gene expression matrices (`filtered_feature_bc_matrix.h5`, `raw_feature_bc_matrix.h5`, `raw_probe_bc_matrix.h5`)
- Spatial metadata (`spatial/tissue_positions.csv`, `spatial/scalefactors_json.json`)
- Quality control files (`metrics_summary.csv`, `web_summary.html`)
- Alignment images (`spatial/aligned_tissue_image.jpg`, `spatial/cytassist_image.tiff`)
- Loupe Browser file (`cloupe.cloupe`)

#### spaceranger_outs/visium_hd/

Space Ranger outputs for Visium HD samples. Each sample has a `binned_outputs/` subdirectory containing results at multiple bin resolutions:
- `square_002um/` - 2 µm × 2 µm square bins
- `square_008um/` - 8 µm × 8 µm square bins (includes `cloupe.cloupe`)
- `square_016um/` - 16 µm × 16 µm square bins
- `square_048um/` - 48 µm × 48 µm square bins

Each resolution contains similar files to Visium outputs, with `tissue_positions.parquet` instead of `tissue_positions.csv`.

#### xenium_outs/

Xenium Onboard Analysis outputs for Xenium samples (subcellular resolution). Each sample directory contains:
- Cell segmentation data (`cell_boundaries.parquet`, `nucleus_boundaries.parquet`)
- Gene expression matrices (`cell_feature_matrix.h5`, `cell_feature_matrix/`)
- Transcript-level data (`transcripts.parquet`, `transcripts.zarr.zip`)
- Cell metadata (`cells.parquet`, `cells.csv.gz`)
- Morphology images (`morphology.ome.tif`, `morphology_focus/`)
- Analysis results (`analysis/` - clustering, differential expression, PCA, UMAP)
- Quality metrics (`metrics_summary.csv`, `analysis_summary.html`)
- Experiment metadata (`experiment.xenium`, `gene_panel.json`)

These Xenium outputs serve as input for creating both standard AnnData objects and SpatialData objects. The raw outputs can also be explored interactively using [10x Genomics Xenium Explorer](https://www.10xgenomics.com/support/software/xenium-explorer).

### spatialdata_objects/

SpatialData objects for Xenium samples (`.zip` format):

- **xenium/** - Comprehensive spatial data containers including transcripts, cell boundaries, and metadata. Generated by [../scripts/01_preprocessing/xenium/01_make_objects/01b_make_spatialdata_objects.py](../scripts/01_preprocessing/xenium/01_make_objects/01b_make_spatialdata_objects.py).

[SpatialData](https://spatialdata.scverse.org/) is a framework for integrated analysis of transcript-level and cell-level spatial information. **Note:** These `.zip` files need to be unzipped before they can be read. See [../scripts/figures/figure5/5B.py](../scripts/figures/figure5/5B.py) (lines 95-99) for an example of how to unzip and read these objects.
